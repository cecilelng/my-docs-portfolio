# Using Shortcuts

You can be more efficient on Map Editor by using the keybord shortcuts. Memorize the keybord shortcuts to keep your fingers on the keyboard instead of jumping back and forth to the mouse. Depending on your keyboard configuration, the shortcuts can vary.

## AZERTY keyboard configuration { #azerty }

 

| Freefly camera             |                  |
|----------------------------|------------------|
| **Rotate left**            | Shift + Q        |
| **Rotate right**           | Shift + D        |
| **Rotate up**              | Shift + Z        |
| **Rotate down**            | Shift + S        |
| **Move left**              | Q                |
| **Move right**             | D                |
| **Move forward**           | Z                |
| **Move backward**          | S                |
| **Dive in**                | Alt + Z          |
| **Step back**              | Alt + S          |
| **Move up**                | PgUp             |
| **Move down**              | PgDown           |
