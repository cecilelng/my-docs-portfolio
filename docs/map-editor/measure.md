# Measuring distances and slopes
  
The Measuring tool allows you to measure distances (x, y, z) and the associated slope between two points of the sensor map.

## Measuring any distances and slopes between two points

To measure a distance between two points of the sensor map:

1. In the tools bar, click on the **Measure tool** icon ![Measure tool](images/measure.svg){ width="20" height="20" }.   
    An orange point hovers with the pointer in the map window.
2. Place a point on each end of the distance you want to measure.

The following distances are measured and displayed in the **Measuring Tool** section in the **Elements** left pane:

- Distance in meters
- Distance (x, y) in meters
- Distance z in meters
- Slope in degrees and percentages
