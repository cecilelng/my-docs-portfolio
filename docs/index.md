# Welcome to the Map Editor Documentation

## What is the Map Editor?

Map Editor is a map editing tool developed by the HMI & Tools team. It lets you quickly and seamlessly create and edit different types of maps, such as sensor maps and HD maps. You can work on maps generated by MMS from the comfort of your desk.

Map Editor can be resource-intensive, so we recommend running it with a Graphics Processing Unit (GPU).

## Where to start

- New to the tool? Begin with [Navigating the Map Editor](getting-started/navigating.md).
- Building HD maps? See [HD Maps behaviors](hd-maps/behaviors.md) first, then [Creating nodes](hd-maps/nodes.md) and [Creating edges](hd-maps/edges.md).
- Working with LiDAR data? See [Selecting scans](sensor-maps/selectingscans.md).
