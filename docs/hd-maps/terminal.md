# Creating a terminal

The terminal tool allows you to create and place a terminal sign at a specific position. Before you create a terminal, make sure you have created edges. You can only place terminals on edges.

## Creating a terminal { #terminal }

To create a terminal:

1.  In the tool bar, click on the **Terminal** icon ![terminal](../images/terminal.svg).
2.  Place the terminal at the position you want.
3.  *(optional)* In the **Elements** left pane, rename the terminal in the **Terminal** section.

In the **Terminal** section at the bottom of the left pane, you can view the following information: terminal name, terminal ID and the terminal position (x,y,z).
