# Selecting elements

HDmap selection is an essential tool for the creation of maps. With HDmap selection, you can select, edit, move and delete elements.

## Selecting elements { #selecting }

To select an element:

1.  In the tool bar, click on the **HDMap Selection** icon ![HD map selection](../images/hdmapselection.svg).
2.  Do one of the following:
    -   Click on the element you want to select.
    -   Click and drag the mouse cursor to select the elements.

**Result:** The selected elements are colored in yellow. At the bottom of the left pane, you can see the properties and the number of selected elements.

## Editing selected elements { #editing }

To edit an element:

1.  In the tool bar, click on the **HDMap Selection** icon ![HD map selection](../images/hdmapselection.svg).

2.  Select the element you want to edit.

    **Result:** The selected element appears in yellow and there are control points at each end of the selected element.

3.  Click on a control point to edit the element according to your needs.

## Moving selected elements { #moving }

To move an element:

1.  In the tool bar, click on the **HDMap Selection** icon ![HD map selection](../images/hdmapselection.svg)
2.  Click on the element you want to move and place it at the selected position.

## Deleting selected elements { #deleting }

To delete an element:

1.  In the tool bar, click on the **HDMap Selection** icon ![HD map selection](../images/hdmapselection.svg).
2.  Click on the element you want to delete.
3.  Right-click and select **Delete**.
