# Creating Nodes

To define a site map, you need to create lanes based on road information. Before you create a lane, you first need to create nodes. It's recommended to create nodes at all the gates and intersections.

## Creating nodes { #createnodes }

To create a node:

1.  In the tool bar, click on the **Node** icon ![nodes](../images/nodes.svg).

2.  Click to place the first control point of the node.

3.  Click to place the second control point of the node.

    **Result:** To edit the node, see [Editing nodes](#editnodes)

## Creating nodes from scan centers { #createnodescenter }

To create a node from scan centers:

1.  In the tool bar, click on the **Node from Scan Center** icon ![nodes from scan center](../images/nodefromscancenter.svg).

    **Result:** The scan centers appear on the map. They are represented by squares.

2.  Click on a scan center to create a node.

    **Result:** To edit the node, see [Editing nodes](#editnodes)

## Editing nodes { #editnodes }

To edit a node:

1.  In the tool bar, click on the **HDMap Selection** icon ![HD map selection](../images/hdmapselection.svg).
2.  Select the node you want to edit.
3.  Use one of the control points to adjust the node size.
