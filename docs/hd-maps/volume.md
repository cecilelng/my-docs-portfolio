# Testing the size of a vehicle

The **Volume test** tool allows you to define the length, width and height of a vehicle and test this vehicle on a lane.

## Testing a vehicle on a path { #test }

To test a vehicle on a path:

1.  In the tools bar, click on the **Volume test** icon ![volume](../images/volume.svg).

    !!! note

        You can only test a vehicle on a lane.

2.  In the **Volume test** section at the bottom of the **Elements** left pane, enter the following parameters:
    -   Length (in meters)
    -   Width (in meters)
    -   Height (in meters)

3.  Hover the vehicle on the lane to test the dimensions.
